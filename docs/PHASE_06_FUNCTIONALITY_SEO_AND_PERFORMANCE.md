# Phase 6: Functionality, SEO, Accessibility and Performance

## Objective

Make the website functional, discoverable, accessible and performant.

## Functionality

Verify: - Navigation and mobile menu. - Project category filters. -
Project detail routes. - Image galleries and lightbox. - Contact form
validation. - Enquiry database storage. - Email notifications, if mail
configuration and recipient are approved. - Filament create, edit,
delete and publish workflows. - Image uploads and public rendering. -
Draft content is not publicly visible.

## Contact form

Fields: - Full name. - Email. - Phone. - Company or organization. -
Service required. - Project location. - Project description.

Use backend validation, safe storage, spam protection and clear
success/error states. Keep secrets server-side. Do not claim email
delivery works until tested with the configured mail transport.

## SEO

Implement: - Unique title and meta description per page. - Canonical
URLs. - Open Graph metadata. - XML sitemap. - Robots.txt. - Semantic
HTML and heading hierarchy. - Descriptive image alt text. - Organization
structured data using verified details. - Search-friendly project slugs.

## Accessibility

Check: - Keyboard navigation. - Visible focus states. - Colour
contrast. - Semantic landmarks. - Form labels and error announcements. -
Image alternative text. - Reduced-motion preferences. - Mobile menu
accessibility.

## Performance

-   Optimize images and generate WebP/AVIF derivatives where supported.
-   Use responsive image sources.
-   Lazy-load below-the-fold images.
-   Avoid lazy-loading the hero if it harms LCP.
-   Load fonts efficiently.
-   Avoid unnecessary scripts and dependencies.
-   Prevent layout shift.
-   Use appropriate caching.

Measure performance before making numerical claims.

## Deliverables

-   Working interactions.
-   Contact enquiry workflow.
-   SEO implementation.
-   Accessibility review.
-   Performance review and measured results.
