# Phase 3: Design System and Homepage

## Objective

Create the visual foundation and implement the complete CRL homepage.

## Design direction

Use an original architectural editorial aesthetic informed by the FMA
Architects and Schmidt Architects references.

Use: - Restrained CRL red accent. - Charcoal, ivory, stone grey and
white. - Sophisticated typography. - Generous whitespace. - Large,
carefully cropped architectural imagery. - Asymmetric editorial
layouts. - Minimal decorative elements. - Subtle, purposeful
transitions.

Do not copy either benchmark.

## Reusable components

Build and test reusable components for: - Header and navigation. -
Mobile navigation. - Footer. - Hero. - Section headings. - Project
feature. - Project card. - Service feature. - Team profile preview. -
CTA. - Image gallery.

## Homepage sections

1.  Architectural hero.
2.  Company introduction.
3.  Verified company highlights.
4.  Four services preview.
5.  Selected projects.
6.  Company approach.
7.  Why CRL.
8.  Team preview.
9.  Vision and mission.
10. Closing CTA.
11. Footer.

## Content and imagery

Use actual CRL project photographs wherever possible. Do not attribute
generic stock images to CRL. Use only verified facts and avoid invented
metrics.

## Responsive requirements

Test desktop, tablet and mobile compositions. Recompose layouts
intentionally rather than shrinking desktop sections.

## Deliverables

-   Design tokens.
-   Reusable Blade components.
-   Complete responsive homepage.
-   Image optimization approach.
-   Visual review notes.

## Approval gate

Present the homepage for review before implementing all internal pages.
